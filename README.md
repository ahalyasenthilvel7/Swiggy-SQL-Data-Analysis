# 🍔 Swiggy SQL Data Analysis

## 📌 Project Overview

This project is a **Swiggy food delivery database analysis using MySQL**.

I created a relational database and solved **150 SQL questions** based on customers, restaurants, orders, payments, deliveries, and reviews.

The project helped me practice SQL from **basic to advanced queries** and understand how SQL can be used to solve real-world business problems.

## 🗄️ Database Tables

* Customers
* Restaurants
* MenuCategories
* MenuItems
* Orders
* DeliveryPartners
* Delivery
* Payments
* Reviews

## 📊 What I Analyzed

The 150 questions cover:

* Customer analysis
* Restaurant analysis
* Order analysis
* Revenue and payment analysis
* Delivery analysis
* Customer reviews and ratings
* Date and time analysis
* Business-related queries

## 🛠️ SQL Concepts Used

* SELECT, WHERE, ORDER BY
* GROUP BY & HAVING
* Aggregate Functions
* INNER JOIN & LEFT JOIN
* Subqueries
* CTEs
* Window Functions
* RANK(), DENSE_RANK(), NTILE()
* Date & Time Functions
* String Functions
* CASE Statements
* Indexing

## 🧠 Skills Demonstrated

**SQL | MySQL | Database Management | Data Analysis | Analytical Thinking | Problem Solving**

## ▶️ How to Run

1. Open the `Swiggy Data Analysis.sql` file in **MySQL Workbench**.
2. Run the script to create the database and tables.
3. Insert the sample data.
4. Execute the 150 SQL questions and explore the results.

## 📌 Key Takeaway

This project gave me hands-on experience in using **SQL to analyze a real-world food delivery business scenario** and strengthened my understanding of both basic and advanced SQL concepts.
